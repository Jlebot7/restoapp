✨ Buenas Prácticas de Ingeniería Aplicadas

  • Arquitectura MPA: Navegación nativa entre páginas independientes HTML (`index.html`, `pedido.html`, `login.html`, `admin.html`).
  • Modularización JS: Código desacoplado utilizando ES Modules nativos por responsabilidad (`menu.js`, `auth.js`, `pedidos.js`, `ui.js`).
  • Pruebas Automatizadas: Suite de pruebas unitarias zero-dependencies en `tests/pedidos.test.js` y ejecutor web `tests/run-tests.html`.
  • Validaciones Estrictas: Filtro de enteros positivos, precios acotados, sanitización contra XSS y mensajes de error detallados.
  • Limpieza de Código Muerto: Remoción total de funciones obsoletas (`funcionObsoletaCalculoAnterior`), CSS redundante y credenciales en cliente.
